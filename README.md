# Sistema-de-Seguranca-Inteligente
O projeto consiste em um protótipo funcional de um sistema de segurança para cofres ou caixas de valores, aplicável a residências e comércios. O sistema utiliza um sensor de luminosidade (LDR) para monitorar a presença de um feixe de luz (simulado pela lanterna de um celular) que incide diretamente sobre ele.
A solução integra um microcontrolador Arduino Uno, um display LCD para interface visual, um buzzer para alarme sonoro e um servo motor que atua como a trava física do cofre. O grande diferencial deste projeto é a lógica de estado (Armado / Desarmado) e o comportamento do alarme, garantindo que a segurança não possa ser burlada facilmente por um intruso.
